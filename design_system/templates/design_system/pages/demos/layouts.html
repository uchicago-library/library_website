Section navigation with right sidebar

The section's pages sit in a col-lg-3 column on the left, the current page marked with aria-current. Below lg they move into an offcanvas panel, opened by the "In this section" button, so the content starts near the top of a phone screen.

The rest of the row is col-lg-9, split again into the main column and the sidebar. The sidebar stays below the content until xl, then the page splits 3/6/3. Splitting at lg would leave each side column too narrow for tables and lists.

Without a right sidebar, the main column takes the whole col-lg-9.

Single column

A centred column using container-md with col-lg-10 mx-auto. This holds the line length near a comfortable reading measure, which is why every documentation page on this site uses it.

Best for articles, documentation and forms — anywhere focus and readability matter more than density.
